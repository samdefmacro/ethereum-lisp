Scope

This revision adds a deterministic integration regression for the concrete Hive
LargeTxRequest failure retained from the exact-f79f5b2e devp2p r39 run. The test
uses the real eth Transactions and GetPooledTransactions codecs, eth gossip
message handlers, the production devnet peer serve backend, and the real txpool
admission path.

The test signs 2,000 consecutive dynamic-fee transactions from one funded
sender, sends them in one encoded Transactions payload, and proves that the
backend invokes batch admission once without scalar fallback. It asserts all
2,000 enter the pending pool, sends all 2,000 hashes in a second peer's encoded
GetPooledTransactions request, preserves the request ID, accepts the bounded
256-transaction production response, and checks every returned transaction
belongs to the sent set.

Limits

This local RED/GREEN regression protects the batch admission and request/reply
handler shape. It is not a successful Hive devp2p rerun and does not close that
gate. The independently rejected r40 request remains rejected because the test
host lacks its fail-closed free-space precondition. This evidence also does not
prove Hoodi convergence, eth_syncing=false, shadow comparison, or validator
soak acceptance.
