Behavioral contract

A GetAccountRange request whose root is an existing account's non-empty storage
root must not be interpreted as a state root. The snap server returns the
matching request ID with no accounts and no proof nodes.

Regression

tests/eth-pump-tests.lisp adds:
  ETH-PEER-RUN-SESSION-IGNORES-A-STORAGE-ROOT-AS-A-SNAP-ACCOUNT-ROOT

The fixture creates real non-empty account storage, derives its committed
storage root, and proves that root differs from the state's account-trie root.
It deliberately makes the state provider return the current state for the
requested storage root, then drives the request through the production peer
session, SNAP wire codec, request router, and persistent SNAP backend. The
backend's final root check must still reject the namespace-confused result.
The test asserts the exact provider lookup, response type and ID, and empty
accounts and proof lists.
