Scope

The pinned geth interoperability test distinguishes three inverted
GetAccountRange requests:

1. origin ff..ff, limit 00..00: no available account exists at or after the
   origin, so the response has zero accounts.
2. origin firstKey, limit firstKey-1: the server returns firstKey once and
   stops, even though the limit is below the available origin.
3. origin firstKey, limit 00..00: the server likewise returns firstKey once.
