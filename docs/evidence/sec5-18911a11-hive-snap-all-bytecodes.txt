chain-record database, requests their content hashes through the production

response codec, and send path, and verifies that a 100,000-byte budget returns

code records and fall back only to the empty in-memory state fixture. The
focused regression then failed 0/1 at its exact three-item cardinality
assertion. The mutation was fully reverted; the accepted revision changes only
the test.
