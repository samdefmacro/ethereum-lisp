Scope

- Empty synthetic blocks now receive a complete canonical header and body:
  parent hash, empty transaction/receipt roots, zero logs bloom, zero nonce,
  state root, gas/header overrides, and fork-appropriate Shanghai withdrawals,
  Cancun blob/beacon fields, and Prague requests hash.
- Such blocks expose their real block hash and size through the ordinary block
  serializer, and a following synthetic block uses that hash as parentHash.
- A synthetic block is hashed only if its parent header has materialized body
  commitments. Non-empty blocks remain deliberately unhashed until simulated
  transactions and receipts are assembled; an empty block after such an
  incomplete parent is not assigned a plausible but false hash.
