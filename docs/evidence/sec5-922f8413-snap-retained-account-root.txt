Behavioral contract

A GetAccountRange request for a retained historical state root is served from
the root-indexed state provider rather than from the current state. The response
retains its request ID and contains the historical account and a non-empty
proof.

Regression

tests/eth-pump-tests.lisp adds:
  ETH-PEER-RUN-SESSION-SERVES-A-PROVIDER-RESOLVED-SNAP-ACCOUNT-ROOT

The test creates distinct current and historical states, asserts their roots
differ, records the exact provider lookup, and drives the request through the
production eth peer session, SNAP wire codec, request router, and persistent
SNAP backend. It checks the response type and ID, provider call count/root,
historical account hash, account count, and proof presence.
