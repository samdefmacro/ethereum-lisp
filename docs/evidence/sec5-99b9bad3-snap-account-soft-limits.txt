Behavioral contract

GetAccountRange uses its byte argument as a soft response target. When the
first available account is larger than the requested budget, the server still
returns that first account. Pinned geth exercises both a one-byte target and a
zero-byte target and expects exactly one account for each.

Regression

ETH-PEER-RUN-SESSION-SERVES-FIRST-SNAP-ACCOUNT-OVER-SOFT-LIMIT creates three
committed accounts, derives the actual first secure-trie key, and sends both
requests through the production eth-peer-run-session SNAP dispatcher, wire
codec, request router, and persistent SNAP backend. It verifies the response
message kind, both request IDs, exact one-account cardinality, and the returned
secure key.
