What this revision changes for the live run, relative to 75b0b7a7:

- A partitioned storage trie whose sixteen cursors all complete under one
  root with full key-space coverage is walked at write time (bounded at
  1,048,576 nodes, every node present and hash-correct, storage leaves
  within the uint256 ceiling); on success the importer publishes
  snap-healed-storage-root-v3: and deletes the walked nodes' incomplete
  markers in one batch. Any refusal writes nothing. On the fixtures the
  marker population at heal entry drops from 4,265 per 2,500-slot contract
  to zero, and a chunked contract's account leaf is closed by the range
  phase instead of withheld.
- The healer's checkpoint room no longer binds the local read width while
  the frontier is above +snap-sync-heal-checkpoint-max-works+ (8,192), where
  no checkpoint can be written anyway; the width stays 130 there instead of
  falling to one after 262,144 processed nodes.
- A local read batch carries post-order sentinels past itself instead of
  closing at the first one, bounded so the frontier cannot exceed what a
  checkpoint records; sentinels are restored below every work the batch
  exposed, and a test fails on any marker deleted above an unresolved child.
