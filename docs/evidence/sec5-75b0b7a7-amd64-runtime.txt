What this revision changes for the live run, relative to 3305307d:

- The store scheme marker is #(7). An account-path trie node is written by
  the range phase only when its whole subtree and every code hash and
  storage root it names are durable (docs/snap-account-closure.md, I1), and
  the healer skips a present, unmarked account node without descending. A
  #(6) datadir opens and resyncs; datadir-3305307d is therefore not reused.
- The snap/1 server no longer persists the trie it serves.
- The healer's local read batch stays 130 wide above the 131,072-work live
  frontier bound instead of collapsing to width one, and the per-node path
  no longer builds generic sequences. peer.snap.heal_progress carries two
  new fields, localReadBatches and localReadWorks.
- The node closes every cached RocksDB handle and releases the background
  thread pools before exit(3), on SIGTERM, return and error exit.
- A WebSocket session deregisters its shutdown closeable, and a client that
  hangs up before its upgrade request no longer spins a core.
