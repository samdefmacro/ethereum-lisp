Scope

The accepted regression builds a deterministic three-account state trie and
drives the production eth+snap session pump, request codec, SNAP dispatcher,
persistent backend account-trie traversal, response codec, and send path. It
constructs the pinned request shape with three singleton account path sets at
nibble lengths 11, 2, and 1, in that deliberately non-key-sorted order, under a
5,000-byte response budget.

The deterministic fixture makes the first requested path absent and the second
and third present. The response must preserve request ID 82, contain exactly
three positional node items, keep the required zero-length placeholder first,
and return the two available encoded trie nodes in their original request
positions. Expected nodes are derived directly from the deterministic account
trie before the request enters the independent production session/backend path.

the test.
