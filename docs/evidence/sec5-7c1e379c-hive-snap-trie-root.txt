Scope

The accepted regression drives the production eth+snap session pump, request
codec, SNAP dispatcher, response codec, and persistent SNAP backend. It creates
a non-empty state trie, requests the account-trie root path `{0}`, then follows
it with a storage path set whose short account key `{1}` normalizes to a missing
account. The server must return exactly the requested root node, omit nodes for
the unavailable storage account, preserve request ID 79, and leave the shared
session usable. The returned node is cryptographically tied to the requested
root by asserting that its Keccak-256 hash equals the request root.

This mirrors the pinned geth case's path-set shape and `expHashes` contract. The
local state is deterministic rather than a copy of Hive's testchain, so the
assertion derives the exact local root instead of importing geth's chain-specific
hard-coded hash.
