BlobTxAvailabilityFailure both failed because the client compared a received
pooled blob wrapper against the complete network-wrapper byte length. Pinned
geth's ETH/72 announcement uses BlobPool `SizeWithoutBlob`, which adds the
canonical typed transaction's `Transaction.Size()` to the separately framed
sidecar list. Those formulas differ by one byte when the outer RLP list crosses
its long-list prefix boundary.

Revision 03957929 introduces one announcement-size helper shared by outbound
NewPooledTransactionHashes metadata and inbound response validation. A focused
RED regression crosses that RLP boundary; the accepted implementation uses the
geth-compatible size and preserves the earlier zero-blob eth/72 behavior.
