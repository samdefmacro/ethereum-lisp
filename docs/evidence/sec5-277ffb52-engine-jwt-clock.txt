The transport sampled the service now-provider before entering the potentially
blocking persistent-connection read. A consensus client creates the JWT when it
sends the request, so a request arriving after that stale clock sample appeared
more than the allowed freshness window in the future. The failure was in server
clock placement, not the shared secret or JWT signature.

RED/GREEN repair

The regression uses a deterministic SBCL Gray input stream. The stream advances
the service clock from 100 to 200 when request intake begins, while the request
carries a correctly signed token with iat=200. Before the repair the request was
rejected and the focused selector reported 0 passed, 1 failed. The repair passes
the now-provider through the service and samples it exactly once after a complete
request has been read, immediately before request authentication and dispatch.
Existing explicit :now callers remain supported.
