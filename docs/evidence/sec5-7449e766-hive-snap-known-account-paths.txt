Scope

The accepted regression builds a deterministic three-account state trie and
drives the production eth+snap session pump, request codec, SNAP dispatcher,
persistent backend account-trie traversal, response codec, and send path. It
constructs the pinned request shape with 65 singleton account path sets, one for
every secure-key prefix length from 1 through 65, under a 5,000-byte response
budget. As in pinned geth, the last selected nibble is replaced with zero before
hex-prefix compact encoding, including removal of the terminator at length 65.

The fixture yields two available encoded trie nodes followed by 63 unavailable
paths. The response must preserve request ID 83 and all 65 positions, including
every required zero-length placeholder. Expected nodes are derived directly
from the deterministic account trie before the request enters the independent
production session/backend path.
