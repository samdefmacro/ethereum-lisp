Local regression boundary

`ETH-72-GET-CELLS-PRODUCTION-HANDOFF-ADMITS-POOLED-BLOB` exercises the complete
in-process production handoff:

- two eth/72 peers receive the same typed, sized blob announcement;
- the selected peer's first session-pump action sends GetPooledTransactions;
- its asynchronous PooledTransactions handler validates the retained request
  metadata and queues the omitted-payload blob transaction for Cells;
- the next session-pump action requests the exact hash with a 16-byte all-ones
  full-custody mask;
- the cell assembler reconstructs the blob and invokes KZG verification exactly
  once with the expected commitment and all 128 proofs;
- transaction and sidecar admission occur only after that verification, while
  the duplicate peer's independent announcement remains queued.

The synthetic verifier checks its complete input boundary but does not assert
cryptographic validity. Existing implementation behavior was already correct,
so this slice is regression-only.

so its omitted-blob callback did not queue the transaction. The focused gate
