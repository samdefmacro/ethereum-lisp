## Scope

This revision closes the remaining bounded RPC-21 behavior:

- one gas-oracle state is owned by each RPC context and shared across requests;
- the recommendation is cached by canonical head hash;
- empty blocks sample the last calculated recommendation rather than the startup fallback;
- sparse history extends from 20 to at most 40 non-genesis blocks;
- context rebinding resets state when the chain store or chain configuration changes;
- cache recomputation and publication are serialized;
- invalid injected oracle state is rejected at RPC-context construction.

`eth_feeHistory` remains a separate gas-weighted implementation.

## Reference review

The implementation was reviewed against pinned geth
`eth/gasprice/gasprice.go:155-233`. A disputed review claim that geth reads only
39 all-one-sample blocks was independently rejected: after the twentieth result,
`len(results)=19` and `exp=19`, so `19 + 1 + 19 < 40` launches the fortieth
request. The focused regression directly asserts a 40-sample history.

Geth completion order is nondeterministic when blocks yield mixed sample counts.
The synchronous implementation chooses an admissible geth completion outcome:
after the initial 20 blocks, it extends until it has 40 samples or has read 40
blocks. No fixed reference mismatch was found.

Independent review also found and caused repairs for chain-bound state surviving
`rpc-context-rebind`, missing injection validation, and stale gap documentation.
